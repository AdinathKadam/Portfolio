# Adinath Kadam — Portfolio

A single static page. No build step, no server, free to host.

## Put it live on GitHub Pages (free)
1. Sign in at github.com (create a free account if needed).
2. New repository -> name it `adinathkadam.github.io` (public).
3. "Add file" -> "Upload files" -> drag in `index.html` and the `files/` folder -> Commit.
4. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main` / root -> Save.
5. Wait ~1 minute. Your live URL appears on that same Pages screen.

## Edit it later (it's meant to be ongoing)
- Small text change: open `index.html` in the repo, click the pencil, edit, commit.
- New gallery photo: just upload it into `files/` using the EXACT filename listed in
  `files/README.txt` (e.g. `ibac-certificate.jpg`). The page finds it automatically.
- New paper/app link: open index.html, find the matching `href="#"`, replace with the real link.
- The page redeploys automatically after each commit.

## Gallery / lightbox
Clicking any tile in the "Proof & Record" section opens it full-size in an overlay
(arrows to move between items, click outside or Esc to close). Tiles with no file
yet show a "Coming" placeholder — safe to leave as-is until you have the asset.

## Custom domain (optional, ~$10/yr)
Buy a domain, add it under Settings -> Pages -> Custom domain. Hosting stays free.
